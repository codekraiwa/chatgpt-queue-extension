## Short description

## Category

## Language

## Single purpose
Prompt & Leave queues and monitors user-selected work across ChatGPT conversations, then alerts the user when responses or queued work finish.

## Detailed description
Stop babysitting ChatGPT tabs.

Prompt & Leave lets you line up prompts in a strict FIFO queue, leave ChatGPT working in the background, and come back when the work is ready.

### What it does
- Queue multiple prompts in each ChatGPT conversation.
- Run queued prompts automatically in first-in, first-out order.
- Monitor multiple open ChatGPT tabs from one popup dashboard.
- See which chats are working, queued, completed, or idle.
- Jump directly to the relevant ChatGPT tab or open its queue.
- Receive completion notifications that route back to the correct tab.
- See how many queued items remain and whether the full queue has finished.
- Play configurable completion sounds, including volume and repeat controls.
- Queue supported image attachments with prompts.

### Built for multi-chat workflows
Prompt & Leave is useful when you run research, coding, writing, analysis, or other longer tasks across several ChatGPT conversations and do not want to manually watch each response finish before sending the next prompt.

### Privacy-first architecture
Prompt & Leave has no developer-owned backend, analytics SDK, advertising SDK, or tracker. Queue data is processed locally in the browser. The extension interacts only with ChatGPT to provide its queueing and monitoring features.

Prompt & Leave is an independent browser extension and is not affiliated with or endorsed by OpenAI.
