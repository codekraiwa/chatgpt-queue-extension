# Privacy Policy — Prompt & Leave, ChatGPT Queue

**Last updated: October 5, 2026**

Prompt & Leave, ChatGPT Queue ("Prompt & Leave") is a Chrome extension that lets users queue prompts in ChatGPT, monitor multiple ChatGPT tabs, and receive completion notifications.

## Data the extension handles

Prompt & Leave handles only the data needed to provide its user-facing features:

- **Queued prompt text** that you enter into the Prompt & Leave queue.
- **Images you explicitly attach to queued prompts.**
- **ChatGPT tab information**, such as the title, URL, queue count, and working/completed state, so the extension can show a multi-tab dashboard and return you to the relevant tab.
- **A limited portion of ChatGPT page content locally** to determine whether a response is still being generated or has finished. Prompt & Leave does not store full assistant responses for analytics or profiling.
- **Extension settings**, such as notification and sound preferences.

## How data is stored

Queued prompt text, queue state, and queued image data are stored locally in your browser using browser storage available to the ChatGPT page and extension. Notification and sound preferences may be stored with Chrome Sync so they can follow your Chrome profile.

## Data transmission

Prompt & Leave does **not** operate a developer-owned server and does not send your queued prompts, attached images, ChatGPT conversations, or browsing activity to the developer.

When Prompt & Leave runs a queued item, it places the prompt and any user-selected attachment into the ChatGPT interface. Those interactions are then handled by ChatGPT/OpenAI under their own terms and privacy practices.

The extension does not include analytics, advertising SDKs, trackers, or remote code.

## Data sharing and sale

The developer does not sell, rent, or share your data with advertisers, data brokers, or other third parties. The extension does not use user data for advertising, credit decisions, or unrelated profiling.

## Permissions

Prompt & Leave requests only permissions needed for its current features:

- **storage** — saves extension settings, including notification and sound preferences.
- **notifications** — shows a Chrome notification when work is complete.
- **offscreen** — plays a completion sound while ChatGPT is in the background.
- **chatgpt.com access** — adds the queue interface, observes generation state, runs queued prompts, and identifies the relevant ChatGPT tabs.

## Data retention and deletion

Local queue data remains in the browser until it is completed, removed by the user, cleared by the user, or browser/site storage is cleared. Extension settings remain until changed, Chrome Sync data is cleared, or the extension is uninstalled.

Uninstalling the extension removes extension-owned Chrome storage according to Chrome behavior. ChatGPT site storage can also be cleared through Chrome's site-data controls.

## Security

Prompt & Leave is designed to keep its own queue data processing local to the browser. It does not transmit user data to a developer backend.

## Chrome Web Store Limited Use

Prompt & Leave's use of information is limited to providing and improving the extension's single purpose: queueing and monitoring ChatGPT work and notifying users when that work completes.

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Changes

If this policy changes in a way that materially affects how user data is handled, this document and the Chrome Web Store disclosures will be updated before the changed practice is released.
